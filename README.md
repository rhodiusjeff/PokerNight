# Poker Night

Project planning and governance live in [control-plane/README.md](control-plane/README.md).
Activate `.cp-venv` before running framework helpers.

The local V0.8.1 planning workflow is `/horizon`, `/plan-work`, and `/admit-plan` through
shared skills available to Planning, Codegen and Lifecycle Facilitator. Capture precedes
proposal; independent review, actual approval and publication remain separate boundaries.
`/admit-plan` is LOCAL/MOCK only. Hosted admission and new operational execution are disabled.
Existing legacy H000 workflows remain supported without automatic migration.

See the [user guide](control-plane/framework/docs/control-system-user-guide.md) for workflow
and limits. No product implementation, admission or release readiness follows from installation.
